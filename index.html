Guide de prise de mesures topographiques par trilatération

1
Définir les points de référence (A, B, C…)
Dans le panel Points de référence, ajoutez au minimum 2 points dont vous connaissez les coordonnées X et Y. Ces points sont fixes sur le terrain (piquets, coins de bâtiment…).

Exemple : A = (0, 0) · B = (10, 0) · C = (5, 8)
2
Régler le niveau laser
HI = Hauteur de l'instrument (hauteur du laser au-dessus du sol).
Mire référence = Lecture sur la mire placée à un point de cote connue (Z=0 par convention).

La différence de cote Z est calculée automatiquement : Z = (HI − mire P) − (HI − mire réf)
3
Charger le croquis (optionnel)
Dans le panel Références, bouton 📎 Croquis — chargez une image du plan de situation pour vous repérer facilement pendant le relevé. Accessible à tout moment via 🗺 Plan.
4
Exporter la session préparatoire
Une fois les références encodées au bureau, exportez le JSON via Export & Session → ⬇ JSON. Sur le terrain, importez ce fichier pour retrouver toutes vos références.
1
Lancer le mode terrain 📍
Le bouton flottant 📍 (bas droite) apparaît dès que 2 références sont configurées. Il ouvre l'interface optimisée pour smartphone.
2
Étape 1 — Hauteur de mire en P
Placez la mire sur le point à mesurer. Lisez la hauteur sur la mire et encodez-la. Appuyez sur ↵ Entrée pour passer à l'étape suivante.
3
Étape 2 — Distances
Visez chaque point de référence avec le télémètre laser. Appuyez sur la tuile du point, encodez la distance lue, validez avec ✓. Faites-le pour au minimum 2 références.

Plus de distances = meilleure précision. Le spread (déviation) s'affiche en temps réel.
4
Étape 3 — Clôture
Donnez un nom au point (optionnel). Choisissez si c'est un Point P (relevé terrain) ou une Référence U (futur point de stationnnement). Appliquez un offset ΔX/ΔY/ΔZ en cm si le point est décalé (ex: sous une haie).
5
Étape 4 — Plan
Le plan 2D affiche le nouveau point mis en évidence. Si une seule paire de références a été utilisée, le bouton ↔ Côté miroir permet de basculer entre les deux solutions géométriques. Cliquez 📍 Point suivant pour enchaîner.
🔵
Qu'est-ce qu'un point U ?
Un point dont la position est inconnue au départ mais qu'on cherche à déterminer par triangulation depuis plusieurs stations. Une fois résolu, il devient utilisable comme référence pour d'autres mesures.
1
Créer un point U
Dans le panel Points inconnus, ajoutez un U. Il passe en mode "collecte d'observations".
2
Collecter les observations
Depuis plusieurs points P déjà mesurés, encodez la distance vers U. Chaque paire (station, distance) est une observation. Minimum 2 observations depuis des stations différentes pour résoudre U.
3
Résoudre et activer
Cliquez Calculer sur la carte U → les intersections convergent. Confirmez la position, puis Activer comme référence pour l'utiliser dans les mesures suivantes.
💡
Créer un U directement par mesure
À l'étape 3 du mode terrain, sélectionnez 🔵 Référence U au lieu de Point P. Le point est créé immédiatement comme U résolu, sans passer par la collecte d'observations.
📋
CSV — Données brutes
Exporte tous les points avec X, Y, Z, précision et déviation. Lisible dans Excel / LibreOffice. Idéal pour un traitement ultérieur.
💾
JSON — Session complète
Exporte tout : références, points P, points U, périmètre, HI, croquis, seuil d'alerte. Permet de reprendre le travail exactement là où vous l'avez laissé via ⬆ Importer.
⬡
OBJ / DXF — Maillage 3D
Exporte le maillage TIN (triangulation) en 3D. OBJ pour Autodesk Inventor / Fusion 360. DXF pour AutoCAD. Choisissez l'unité (mm par défaut pour Inventor).
📤
Rapport ZIP
Génère un ZIP contenant tous les fichiers cochés (PNG du plan, CSV, OBJ, DXF, JSON). Sur iOS, s'ouvre dans la feuille de partage native (Mail, AirDrop, Fichiers…).
📐
Géométrie optimale
Pour une bonne précision, les références doivent former un triangle autour du point mesuré. Évitez les références alignées (colinéarité → alerte dans l'app). Plus l'angle entre deux lignes de visée est proche de 90°, meilleure est la précision.
🎯
Déviation et précision
Le spread = écart maximal entre les intersections de chaque paire. Un spread < 50mm est excellent. Entre 50–200mm : acceptable. Au-delà : vérifiez vos mesures.

Réglez le seuil d'alerte dans Niveau laser → Seuil spread selon votre tolérance de chantier.
📱
Utilisation sur smartphone
Installez l'app via Safari → Partager → Sur l'écran d'accueil pour une utilisation hors navigateur. Activez ☀ Écran actif pour éviter la mise en veille pendant le relevé.
💾
Sauvegarde automatique
Chaque point confirmé est sauvegardé automatiquement dans le navigateur (localStorage). En cas de fermeture accidentelle, l'app propose de restaurer la session au redémarrage. Pour une sauvegarde durable, exportez en JSON régulièrement.
🔄
Offset d'un point
Si le point physique est inaccessible (sous une haie, dans l'eau…), mesurez un point décalé et appliquez un offset ΔX/ΔY/ΔZ en cm dans l'étape Clôture. La position finale intègre automatiquement le décalage.
